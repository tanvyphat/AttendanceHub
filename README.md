# AttendanceHub

Internal attendance management system built with React, TypeScript, Vite, Tailwind CSS, Supabase, and ExcelJS.

## Features

- Admin authentication with Supabase Auth
- Daily attendance tracking
- Late arrival detection
- Leave approval workflow
- Attendance history
- Monthly reports
- Excel export
- Employee management

## Deployment

This project is configured for Vercel SPA routing with `vercel.json`.
